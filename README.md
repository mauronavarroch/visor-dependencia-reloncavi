# Visor de dependencia Reloncavi - demostracion

Version de prueba independiente del visor institucional. Abrir index.html o el sitio GitHub Pages del repositorio.

Carga Excel/CSV en memoria, graficos, mapa y tarjetas. Ingreso simulado: administrador o consulta, clave demo. Administracion temporal para crear, editar o retirar registros; historial de la sesion. Vaciar o recargar descarta los datos y cambios; no modifica el Excel original.

No incluye pacientes, bases de datos ni claves institucionales. El ingreso simulado NO protege informacion sensible. No publicar Excel ni datos reales en este repositorio. Las exportaciones voluntarias permanecen en disco. La cartografia y bibliotecas se sirven localmente; connect-src none bloquea conexiones de datos.

Cartografia: OpenStreetMap contributors, ODbL https://www.openstreetmap.org/copyright . Bibliotecas: Leaflet 1.9.4 (BSD-2-Clause) y SheetJS 0.18.5 (Apache-2.0), avisos en sus archivos.

El enlace admin.html redirige a la nueva interfaz; las versiones anteriores permanecen en el historial Git.
